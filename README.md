# Dynamical Processes in Complex Networks (DPT)

This repository contains the computational work for a project on **Dynamical Processes in Complex Networks**, including network construction, SIS epidemic simulations, and comparative analysis.

## Project Contents

### Analysis Notebooks

- `DPT_NETWORK_CONSTRUCTION.ipynb` — Network construction and analysis
- `DPT_SIS_A_AFTER_TC.ipynb` — SIS dynamics analysis after the transition condition
- `DPT_SIS_A_BEFORE_TC.ipynb` — SIS dynamics analysis before the transition condition
- `DPT_SIS_A_NEAR_TC.ipynb` — SIS dynamics analysis near the transition condition
- `DPT_COMPARISON.ipynb` — Comparison of the analyzed dynamical regimes

### Project Report

- `P20_PROJECT_DPT_REPORT.pdf` — Complete project report describing the methodology, analysis, results, and discussion.

## Project Overview

The project investigates dynamical processes on complex networks using network-based modeling and SIS (Susceptible–Infected–Susceptible) dynamics. The analyses examine how network structure and dynamical conditions influence the behavior of the system.
